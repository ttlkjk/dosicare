Product Overview
솔루션 개요
스마트한 통합 QA 플랫폼
Linac QA Hub는 DosiMachine 분석 리포트와 병원 장비의 데이터를 한곳에 모읍니다. 값을 옮겨 적는 일을 줄이고, 기록을 추세와 점검표로 이어 주어 의료물리사가 결과를 살피는 일에 더 집중할 수 있도록 돕습니다.
📋
데이터 중점 관리
점검표를 디지털로 작성해 기록을 파일로 보관하고, 항목별 추세를 오래 살필 수 있습니다.
🔬
리포트 값 자동 읽기
QA 리포트 PDF에서 Flatness, Symmetry 등의 값을 읽어 저장하고 그래프로 보여 줍니다.
🔗
장비 파일 연동
Varian MPC, IBA MyQA, BeamCheck, BeamChecker Plus, PTW QuickCheck, Trajectory Log 파일을 읽어 옮겨 적는 실수를 줄입니다.
📄
점검표 출력과 서명
일간·월간·연간 점검표를 PDF와 Excel로 출력하고, 월간·연간 점검표에 수행자와 물리사 서명을 남깁니다.
✦ 주요 분석 및 관리 기능
  • 일간 MPC 점검 자동 결과 파싱
  • 월간 점검표 수식 자동 계산
  • 연간 점검표 작성과 기록 관리
  • Trajectory Log 기반 MLC 오차 확인
  • Winston-Lutz 결과 저장 · 추세
  • Picket Fence 결과 저장 · 추세
  • StarShot 결과 저장 · 추세
  • PDD · Profile 결과 저장 · 추세

통합 QA 관리 모듈
Daily
일간 QA
장비의 일일 안전과 기계 상태를 빠르게 확인합니다.
  • Door Interlock, 경고등, A/V 확인
  • 레이저, ODI, 콜리메이터 표시기
  • 냉각수와 SF6 가스 상태
  • 영상 획득 장치 (OBI, PV)
Monthly
월간 QA
빔 특성과 기계 항목의 결과를 점검표로 정리합니다.
  • Dosimetry / Mechanical 항목 기록
  • QA 결과를 점검표로 가져오기
  • 계산 항목 수식 자동 계산
  • Tolerance 초과 시 색으로 강조
Yearly
연간 QA
연간 측정 결과를 점검표로 기록하고 문서로 남깁니다.
  • 선량 출력, 기계적 항목
  • Gantry, Field 항목
  • PDF, Excel 출력
  • 수행자, 물리사 서명
